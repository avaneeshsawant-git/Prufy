About Prufy

Prufy is a proof-of-work based productivity platform where users track tasks through actual work logs. Instead of simply marking tasks as complete, users attach proof of their work, making progress visible and meaningful.

Key Features

  • Real-time task management using Firebase
  • Proof-based logging system with file uploads
  • Cloudinary integration for storing work evidence
  • Public / private task visibility
  • Explore other users’ work
  • Clean and distraction-free UI

How It Works

  • Create a task
  • Add logs as proof of work
  • Track your progress visually
  • Make tasks public to share your work
  • Search and explore other users

Philosophy

Most task managers track what you plan to do.

Prufy tracks what you actually did.
